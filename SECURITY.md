# Security policy

Please do not disclose exploitable vulnerabilities, credentials or customer information in public issues.

Report privately through GitHub private vulnerability reporting for this repository when enabled. If unavailable, contact the maintainer through the contact information on https://github.com/enriqueuz to arrange a private channel before sending technical details.

Include the affected revision, minimal synthetic reproduction, expected and observed behavior, and impact. Do not access other tenants, test production systems, send real customer data or execute financial operations to demonstrate a finding.

This repository is an independently maintained source showcase, not a production deployment template. No response-time SLA or security certification is offered. Dependency and infrastructure security require continuing review.
