# 0001: Independent public source snapshot

Status: Accepted

Preserve the real application, tests and evaluation design while excluding operational documentation, credentials, historical evaluation output and maintenance scripts. Write public documentation from the source. License original code under PolyForm Noncommercial 1.0.0; retain dependency ownership.

System authority requires a password-authenticated signed claim, expires within eight hours and is invalidated by password-hash changes. Existing ordinary and legacy administrative cookies do not gain this authority. Destructive system maintenance endpoints are blocked until fresh authentication and independent audit requirements can be implemented and verified. This intentionally changes their API behavior; the external panel must accommodate a denial.

Publication requires isolated integration validation, complete privacy review and resolution of significant security findings. A clean automated scan alone does not satisfy that requirement.
